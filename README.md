# Areg's personal portfolio

This is my personal website to showcase my stuff and interest. Has 2 tabs, one is the homepage featuring cool hover effects which change the text, and the other is my work page where I showcase my great projects.

## How to run the website locally

### Prerequisites

- [Node.js](https://nodejs.org/en)

First, download the source code and install all required packages

```
npm install
```

Then, run the following command to build the website:

```
next build --turbopack
```

After building, run the server:

```
next start
```

And MY website is good to go locally, self-hosted!
